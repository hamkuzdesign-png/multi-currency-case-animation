# Мультивалютный кейс — анимационный прототип

Интерактивный прототип экрана «Мои накопления» с переключением суммы между рублём и иеной, анимацией дохода, периодом доходности и сворачивающейся кнопкой при прокрутке.

**Открыть прототип:** <https://hamkuzdesign-png.github.io/multi-currency-case-animation/>

![QR-код прототипа](prototype-qr.png)

## Локальный запуск

Откройте `index.html` в браузере или запустите любой статический HTTP-сервер из этой папки, например:

```sh
python3 -m http.server 8000
```

Затем перейдите на `http://localhost:8000`.

Все изображения и шрифты находятся в `header-assets/`; сторонние зависимости и сборка не требуются.
